# December Scribbles logo system

## Concept

- **Monogram (DS):** the **D** is drawn as a notebook page. A single handwritten **S** stroke
  sits inside it, and its tail curls back up like the handle of the closed umbrella from the
  brand's Instagram bio (🌂). The D is drawn in ink and the S in the accent colour.
- **Wordmark:** "December" is set in Bricolage Grotesque SemiBold, slightly condensed. It sits
  beside "Scribbles" in Instrument Serif Italic. Two hand-made details make it ownable:
  - the dot of the **i** is a rose ink drop;
  - a quick pen **scribble** underlines "Scribbles" (primary lockup only).
- **Colours:** ink is forest `#1e3326` on light backgrounds and canvas `#f5f2ec` on dark ones.
  The accent is rose `#b0405a` on light and blush `#e9a9b6` on dark.

The letterforms are outlined vector paths, not live text, so the logo looks the same everywhere.

## Files (`apps/web/public/brand/`)

| File                                         | Use                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| `logo.svg` / `logo-dark.svg`                 | Primary lockup for light / dark backgrounds                              |
| `logo-compact.svg` / `logo-compact-dark.svg` | Stacked lockup for narrow headers and mobile                             |
| `monogram.svg` / `monogram-dark.svg`         | Standalone mark (avatars, small UI, social profiles)                     |
| `app-icon.svg`                               | Favicon / app icon: a solid D silhouette with a heavy S, legible at 16px |
| `hero-illustration.svg`                      | Homepage hero art (notebook, umbrella poster, pencil, snow)              |

The site renders the same geometry inline from `apps/web/src/components/logo-art.ts`, through
`<Logo>`, `<Monogram>` and `<Wordmark>` in `components/brand.tsx`, so it follows the theme. The
favicon is `src/app/icon.svg` (a copy of `app-icon.svg`) and `src/app/apple-icon.png` (180px).
The social sharing card (`src/app/opengraph-image.tsx`) uses the primary dark logo.

## Usage rules

- **Clear space:** keep at least the width of the monogram's S clear on every side, roughly
  ¼ of the logo's height.
- **Minimum sizes:**
  - primary lockup: 28px tall;
  - compact lockup: 32px tall;
  - monogram: 16px (use `app-icon.svg` below 24px).
- **Use the compact lockup** where the primary would be narrower than about 190px. The site
  header switches below 380px.
- Size by height only. Never stretch, crop, rotate, recolour outside the light/dark pairs,
  re-type the name in another font, or swap the mark for an emoji.

## Regenerating

The logo and hero art are generated by `logo-generator.py` and `hero-generator.py` in this
folder. They need Python with `fonttools` and `uharfbuzz`, plus these fonts in a `fonts/` folder
next to the script, both under the SIL Open Font License, which allows outlining:

- `Bricolage.ttf`: Bricolage Grotesque variable font from `github.com/google/fonts/ofl/bricolagegrotesque`
- `InstrumentSerif-Italic.ttf`: from `github.com/google/fonts/ofl/instrumentserif`

```sh
python logo-generator.py ../../apps/web/public/brand ../../apps/web/src/components/logo-art.ts
python hero-generator.py ../../apps/web/public/brand/hero-illustration.svg
cp ../../apps/web/public/brand/app-icon.svg ../../apps/web/src/app/icon.svg
```
